AI Settings

Choose your AI mode. Selecting Ollama checks its local service; remote providers are contacted only when you test the connection or send a message.

Install Ollama, start the service, then run ollama pull llama3.2. If browser access is blocked, review Ollama's allowed origins (OLLAMA_ORIGINS) or run LUZYX locally. HTTPS sites may be prevented from reaching local HTTP services.

Key security: Saved keys are kept in this browser's localStorage. They are not completely secure and may be exposed by malicious scripts or someone with access to this browser profile. Remove them when no longer needed. Remote provider requests go directly to the provider you selected.
